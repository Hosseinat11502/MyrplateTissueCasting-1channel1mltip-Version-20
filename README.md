# MyrplateTissueCasting-1channel1mltip-Version-20
Automated dispensing of cell-laden collagen master mix into a 48-well **myrPlate** (`myrplate_48_wellplate_800ul`) using an Opentrons **Flex** with a single-channel 1000 µL pipette. Each tip aspirates once from a user-selected well of a NEST 2 mL 96-well deep-well source plate and dispenses into one 4-well column segment of the myrPlate.
